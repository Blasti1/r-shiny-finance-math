📊 ATLAS R/LAB — интерактивная лаборатория финансов и математики

💰 Финансы · 📐 Производные · 📈 Статистика

ATLAS R/LAB — образовательное веб-приложение, разработанное на языке программирования R с использованием фреймворка Shiny.

Проект объединяет три направления вычислений в едином интерактивном пространстве. Пользователь может задавать исходные данные, выполнять математические и финансовые расчёты, изучать графики и получать результаты в удобном формате.

🎯 Цель проекта
Разработка современного образовательного веб-приложения для автоматизации финансовых, математических и статистических вычислений с возможностью интерактивного изменения параметров и визуализации результатов.

✨ Основные возможности

💰 01. Финансовые расчёты

Модуль предназначен для решения практических задач финансовой математики.

Возможности:

Расчёт банковского вклада с ежемесячной капитализацией процентов.
Учёт регулярного пополнения вклада.
Вычисление аннуитетных платежей по кредиту.
Определение общей суммы выплат и переплаты.
Расчёт чистой приведённой стоимости (NPV) инвестиционного проекта.
Анализ денежных потоков за период до 30 лет.
Построение графиков и таблиц финансовых показателей.
Экспорт результатов расчётов в CSV.

📐 02. Производные функций

Модуль позволяет исследовать математические функции и изучать основы дифференциального исчисления.
Возможности:
Аналитическое вычисление производной функции.
Определение значения функции в заданной точке.
Вычисление значения производной в точке.
Определение углового коэффициента касательной.
Формирование уравнения касательной.
Построение графика исходной функции и касательной.
Поддерживаются степенные, тригонометрические, показательные и логарифмические выражения, составленные из разрешённых математических операций и функций.

📊 03. Статистический анализ

Модуль предназначен для обработки числовых выборок и изучения статистических характеристик.
Возможности:
Расчёт среднего арифметического и медианы.
Определение выборочной дисперсии.
Вычисление стандартного отклонения.
Определение минимального и максимального значений.
Расчёт квартилей.
Построение 95% доверительного интервала для среднего.
Создание гистограммы распределения.
Построение диаграммы размаха (Boxplot).
Экспорт таблицы статистических показателей в CSV.

🎨 Особенности интерфейса

ATLAS R/LAB выполнен в стиле современной аналитической платформы.
Светлая цветовая гамма с тёмно-синими и терракотовыми акцентами.
Три отдельных интерактивных раздела.
Карточки ключевых результатов.
Автоматическое обновление вычислений при изменении данных.
Графическая визуализация результатов.
Адаптивная компоновка для экранов разных размеров.
Полностью русскоязычный интерфейс.

🚀 Установка и запуск

Шаг 1. Установите R и RStudio Desktop.

Шаг 2. Скачайте файлы проекта из репозитория.

Шаг 3. Откройте файл ATLAS_R_Lab.Rproj в RStudio.

Шаг 4. Установите необходимую библиотеку, выполнив в консоли:

install.packages("shiny")

Шаг 5. Откройте файл app.R и нажмите кнопку Run App.

Приложение запустится локально в RStudio или веб-браузере.

Важно: папка www с файлом styles.css должна находиться рядом с app.R.
